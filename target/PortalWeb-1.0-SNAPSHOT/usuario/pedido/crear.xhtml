Ingresa los ítems del pedido

Para agregar productos:
1. El campo de código del ítem es un campo de busqueda que filtra los productos de acuerdo a los que se escriba.

2. Seleccionar el tamaño en centímetros (Si es un producto de la unidad de negocio de Eka cierres), ancho en milímetros (Si es un producto de la unidad de negocio de Tex cintas), o marca (si es un producto de de la unidad de negocio de Kos).

3. Buscar Colores y combinaciones (Si es un producto de la unidad de negocio de Eka cierres o Tex cintas), o calibre (si es un producto de de la unidad de negocio de Kos).

4. El campo de unidad de medida se llena dependiendo del producto seleccionado y no podrá modificarse.

5. Ingresar la cantidad requerida de este producto.

6. Haz clic en Agregar ítem, para que se vaya anexando al pedido.


Para agregar productos:
1. En el campo Código del cliente del ítem, se escribe el código propio usado para identificar el producto en la compañía del cliente, una vez se ingresa el código y se oprima la tecla tab o se haga clic en otro elemento del formulario, automáticamente se diligencian los otros campos del formulario, estos no se pueden modificar.

2. Ingresar la cantidad requerida de este producto.

3. Haz clic en Agregar ítem, para que se vaya anexando al pedido.


Para agregar productos por medio de hoja de calculo .xlsx, debes:
1. Descargar estructura dando clic en el botón:



2. Abrir la estructura descargada.

3. Código del ítem: Ingresar tu código del ítem.

4. Cantidad requerida: Ingresar la cantidad requerida.

5. Haz clic en el botón examinar.

6. Seleccionar el archivo.

7. Haz clic en procesar archivo.


Para agregar productos:
1. En el campo Código del ítem, se selecciona el producto requerido, una vez seleccionado automáticamente se diligencian los otros campos del formulario, estos no se podrán modificar.

2. Ingresar la cantidad requerida de este producto.

3. Haz clic en Agregar ítem, para que se agregue al pedido.
